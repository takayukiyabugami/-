# Intake Checklist

## Use

Use this checklist when the user starts a new story, expands a thin premise, or asks for a full project plan. Ask only for missing information that changes the next writing decision.

## Mandatory Fields

| Field | Confirm |
| --- | --- |
| Working title | Temporary title is enough |
| Core premise | One-sentence hook |
| Format | Short story, chapter, volume plan, serial, scene |
| Genre blend | Main genre plus secondary flavor |
| Target reader feeling | Awe, ache, suspense, warmth, dread, release, etc. |
| POV | First person or third person; single or multiple |
| Protagonist desire | What they want now |
| Protagonist wound | What they avoid admitting |
| Opposition | Person, system, world, self, time limit |
| Ending direction | Closure, cliffhanger, reversal, open wound |

## Useful Optional Fields

- era, location, and social rules
- power system or speculative rule
- romance, violence, horror, or taboo boundaries
- key relationship to foreground
- reference works by abstract trait only, not imitation
- desired prose density: clean, lyrical, spare, cinematic, intimate
- chapter length or serialization cadence

## Project Files

Create or update these sections:

- `concept.md`: premise, promise, theme, tone, constraints
- `characters.md`: desire, wound, contradiction, speech, limits, arc
- `outline.md`: arc map, chapter beats, reversals, foreshadowing ledger
- `manuscript.md`: drafted prose
- `revision-notes.md`: diagnosis, decisions, continuity changes

## Question Discipline

- Ask no more than three questions at once.
- If the answer can be assumed without breaking the story, assume it and label it.
- Do not delay a short sample scene for complete worldbuilding.
- For weak premises, ask for desire and opposition first. Most failures start there.
