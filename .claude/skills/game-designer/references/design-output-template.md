# Design Output Template

Adapt this template to the task. Keep narrow requests narrow.

## Default Design Brief

```markdown
## 前提
- ...

## Design Brief
- ジャンル:
- 対象プレイヤー:
- 目標体験:
- 1プレイ:
- 設計仮説:

## Core Loop
1. ...
2. ...
3. ...

## Rules / Systems
- 基本ルール:
- リソース:
- プレイヤー選択:
- 失敗条件:
- 報酬:

## Combat / Challenge
- 主な脅威:
- プレイヤーの対抗手段:
- 読み合い:
- 失敗から学べる情報:

## Level / Progression
- 導入:
- 展開:
- 山場:
- 回復/安全地帯:
- 成長または解放:

## UX / Controls
- 入力:
- 画面情報:
- フィードバック:
- リトライ導線:

## Difficulty & Balance
- 初期値の方針:
- 調整ノブ:
- 想定される破綻:

## Player Psychology
- 狙う感情:
- 迷わせる点:
- 安心させる点:
- もう一回遊ばせる要因:

## Prototype Test Plan
- 最小実装:
- 観察する行動:
- 成功基準:
- 失敗時の調整:

## Risks / Next Iteration
- ...
```
